# Imagen personalizada de Finance

Coloca aquí la imagen descargada que quieres usar en:

- Splash screen
- Pantalla de inicio de sesión
- Icono de la APK
- Icono de la PWA

Nombre obligatorio del archivo:

`finance-image.jpg`

No necesitas modificar código. Solo sube/reemplaza este archivo con tu imagen y ejecuta el workflow **Build Finance APK** en GitHub Actions.

Recomendación: usa una imagen cuadrada y de buena resolución. La imagen original se conservará sin modificar para splash/login; Android la usará como icono de la aplicación.
